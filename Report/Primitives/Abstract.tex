\begin{spacing}{1.02}
Detecting illicit fund movements across distributed cryptocurrency ledgers remains a difficult problem for automated regulatory surveillance. Conventional graph learning pipelines routinely compress transaction graphs into static, time-invariant snapshots. This assumption erases the temporal ordering of fund dispersion, obscuring rapid multi-hop velocity patterns engineered by bad actors. In practice, prevailing compliance tools produce only solitary binary classifications. These outputs lack structural typology distinctions and omit verifiable subgraphs, depriving investigators of actionable evidentiary trails for Suspicious Activity Report (SAR) filings.

This dissertation presents \textbf{TemporalAML}, a unified framework coupling continuous-time representation learning with multi-typology classification and forensic subgraph extraction. Using the Elliptic Bitcoin benchmark—encompassing 203,769 transaction vertices, 234,355 fund-flow edges, and 49 sequential time windows—the data pipeline integrates 172 node attributes alongside six custom topological indicators under an inductive, leak-free chronological evaluation protocol. Rather than depending on static sinusoidal heuristics, TemporalAML formulates a \textit{Learnable Fourier Time Encoding} layer wherein projection frequencies $\boldsymbol{\omega}$ and phase shifts $\boldsymbol{\phi}$ update dynamically through gradient descent inside a multi-head Temporal Graph Attention Network (TGAT). This direct optimization enables the attention coefficients to adapt to bursty, heavy-tailed transaction intervals. From a shared 128-dimensional temporal embedding, three dedicated heads simultaneously isolate distinct money laundering structures: \textit{Circular Transfers}, \textit{Layering Chains}, and \textit{Smurfing/Fan-Out} dispersals, counteracting severe class skew through weighted multi-task supervision. An integrated GNNExplainer module isolates compact, chronologically sorted causal subgraphs, compiling empirical evidence directly into standardized regulatory SAR narratives.

Phase~1 realizes the full theoretical formulation, end-to-end software pipeline, and baseline empirical checks for TemporalAML. Verification experiments demonstrate non-zero gradient propagation through the temporal Fourier parameters, yielding consistent discriminative gains over fixed-frequency variants on chronological test intervals. These results confirm the methodological viability of the architecture, providing the groundwork for full-scale benchmarking, module ablations, and regulatory stress testing in Dissertation Phase~2.
