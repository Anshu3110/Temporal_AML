\section{Context and Background Study}
\label{sec:intro_background}

\subsection{The Digital Financial Revolution and Its Challenges}

The decentralized digital asset network has revolutionized the way capital is moved today, reducing reliance on traditional clearinghouses and state-regulated banking institutions. By substituting central intermediaries with cryptographic consensus, distributed ledgers maintain a continuous public record of all settlement transactions. This radical transparency, however, carries an operational paradox. While transaction histories remain permanently inspectable on the blockchain, public keys operate pseudonymously. Criminal syndicates take advantage of this, spreading ill-gotten gains across multi-hop schemes and transfer graphs to distance money from illicit sources.

Enforcement of anti-money laundering laws confronts an overwhelming transaction volume on a global scale. Estimates by the United Nations Office on Drugs and Crime (UNODC) indicate that approximately 2\% to 5\% of global economic output, representing nearly \$800 billion to \$2 trillion, is laundered annually through illicit channels~\cite{unodc2023}. This pressure is mirrored directly in cryptocurrency pipelines: market analyses demonstrate that criminal transaction volumes surged significantly across successive reporting periods~\cite{chainalysis2023}. Therefore, automated, graph-native detection systems are imperative to support scalable compliance across vast transaction topologies.

\subsection{Blockchain and Bitcoin}

Bitcoin was introduced in 2008 by Nakamoto~\cite{nakamoto2008bitcoin} as the first decentralized ledger settlement system, utilizing an Unspent Transaction Output (UTXO) accounting structure. The network maintains no explicit account balances; instead, value exists strictly as discrete output objects consumed by subsequent operations. When an entity initiates a transaction, it liquidates existing UTXOs as inputs and mints brand-new outputs for target recipients and change returns. Mathematically speaking, this protocol naturally maps to a directed graph: vertices represent transaction executions, while directed edges trace cryptographic value flows across explicit block confirmation timestamps.

\vspace{0.5em}
\noindent
\textbf{Network Attributes Critical to Graph Compliance:}
\begin{itemize}
	\item \textbf{Pseudonymous Entities:} Addresses correspond to cryptographic public key hashes rather than legal entities; linking these accounts to real identities requires forensic cluster analysis and KYC cross-referencing.
	\item \textbf{Ledger Finality:} Once mined into a valid block, transactions cannot be revoked or rewritten, providing an incorruptible chronological trail.
	\item \textbf{Auditable Provenance:} The open ledger design allows complete backward reconstruction of fund transfers beginning at the 2009 Genesis Block.
	\item \textbf{Ordered Chronology:} Block confirmation times impose an indisputable sequential order on all transaction vertices, creating an ideal substrate for time-conditioned graph neural networks.
\end{itemize}

\subsection{Why Transaction Networks Can Be Modelled as Graphs}

The network of transactions is by nature relational. Instead of treating transactions as isolated data rows, graph models map transfers as interacting topological objects. In this work, the Elliptic benchmark is analyzed, where individual transactions form vertices connected by directed edges representing value transfers~\cite{elliptic2019}. Graph Neural Networks (GNNs) take advantage of this graph structure, relaying neural messages throughout local neighbourhoods to reveal relational laundering patterns that tabular baselines overlook entirely.

\subsection{The Importance of Temporal Information in AML}

Laundering across blockchains depends heavily on time. Financial criminals deliberately tune the tempo and sequence of transfers to outrun automated surveillance:
\begin{itemize}
	\item \textbf{Layering runs} move assets across rapid, back-to-back hops in minutes, distancing illicit capital before anti-fraud officers issue account freezes.
	\item \textbf{Smurfing schemes} stagger fractional payments over extended intervals to evade fixed reporting ceilings.
	\item \textbf{Inter-transaction velocity} provides a stark discriminant between normal commercial settlement and automated evasive churning.
\end{itemize}

Treating these networks as static graphs discards edge sequence information entirely. Worse, unconstrained message passing allows information from subsequent transactions to bleed into predictions for past events, producing invalid temporal leakage. Effective detection requires models that explicitly condition their attention weights on continuous inter-transaction time deltas.

\section{Need Analysis}
\label{sec:intro_need}

\subsection{Limitations of Conventional AML Approaches}
\label{subsec:limitations}

Contemporary Anti-Money Laundering frameworks deployed across cryptocurrency ecosystems confront several structural bottlenecks:

\begin{enumerate}
	\item \textbf{Atemporal Graph Architectures:} Prevailing designs built around Graph Convolutional Networks (GCN)~\cite{kipf2017gcn}, Graph Attention Networks (GAT)~\cite{velivckovic2018gat}, and GraphSAGE~\cite{hamilton2017graphsage} collapse transaction histories into static connectivity graphs. This design discards edge sequence information, blinding models to sequential laundering paths such as rapid multi-hop layering.

	\item \textbf{Look-Ahead Evaluation Leakage:} Evaluating static graph models under random node splits permits message-passing from future time intervals into past targets. This artificially inflates benchmark metrics while obscuring real-world failure, since deployed systems possess only past operational records.

	\item \textbf{Rigid Harmonic Parameterization:} Prior temporal models incorporate time through discrete snapshot discretization or fixed sinusoidal projections borrowed from language modeling~\cite{vaswani2017attention}. Geometric frequency progressions assume stationary temporal spacing, failing when applied to the heavy-tailed, bursty transaction intervals of crypto asset exchanges.

	\item \textbf{Uninformative Binary Flagging:} Most contemporary literature~\cite{weber2019anti, pareja2020evolvegcn} outputs an uncalibrated scalar indicating broad illicit association. This falls short of operational standards, which demand identification of exact structural typologies, such as peeling chains or structured smurfing, alongside evidential paths for regulatory escalation.

	\item \textbf{Opaque Decision Outputs:} Raw probability scores provide no auditable trail. Regulatory authorities mandate that automated AML rejections and escalations feature verifiable, human-inspectable evidence trails~\cite{giese2022explainable}.

	\item \textbf{Absence of Subgraph Forensics:} Existing classifiers fail to extract the precise causal transaction chain triggering an alert, requiring laborious manual trace verification by financial intelligence analysts.
\end{enumerate}

These deficiencies define the primary research questions investigated in this work.

\subsection{Importance of Anti-Money Laundering}
\label{subsec:importance_aml}

Robust financial surveillance underpins international banking stability. The Financial Action Task Force (FATF) estimates that illicit capital transfers siphon between 2\% and 5\% of annual global GDP, translating to roughly \$800 billion to \$2 trillion~\cite{fatf2022}. On-chain crime tracks this expansion: illicit token transfers reached \$20.6 billion in 2022 and sustained an elevated \$24.2 billion volume across 2023~\cite{chainalysis2023}, propelled by cross-border sanctions evasion, ransomware demands, and decentralized market exploits.

\subsection{Why Existing Tools Fall Short}
\label{subsec:shortcomings}

Contemporary monitoring systems exhibit persistent operational vulnerabilities:
\begin{enumerate}
    \item \textbf{Static Value Cutoffs:} Simple threshold rules (such as flagging single transfers above \$10,000) are trivial to bypass using \textit{smurfing}, where actors disperse funds through dozens of coordinated micro-transactions across unlinked wallets.
    \item \textbf{Isolated Tabular Inference:} Tree-based classifiers (e.g., Random Forests, XGBoost) evaluate transaction metadata in isolation, ignoring topological surroundings and failing to recognize cyclic laundering or peeling loops.
    \item \textbf{Uncalibrated Graph Encodings:} Standard GCN and GAT models discard edge timestamps and edge weights, treating edges from years apart as contemporaneous. This introduces catastrophic evaluation leakage and eliminates transaction velocity indicators.
    \item \textbf{Actionless Binary Signals:} High false-alarm rates ($>90\%$ in operational compliance queues) overburden investigators. Lacking localized causal subgraphs that explain \textit{how} a transfer violates policy, compliance teams struggle to construct legally defensible SAR filings.
\end{enumerate}

\section{Problem Identification}
\label{sec:intro_problem}

\subsection{Problem Statement}
\label{subsec:problem_statement}

Existing Anti-Money Laundering systems applied to cryptocurrency networks rely on static graph representations that discard temporal ordering, fixed-frequency time encodings that fail on bursty transaction streams, binary outputs that obscure distinct laundering typologies, and opaque architectures devoid of localized evidence trails. These shortcomings prevent existing systems from meeting the evidentiary thresholds demanded by financial regulators.

\vspace{0.5em}
\noindent\textbf{Formal Problem Statement:} \\[0.5em]
\textit{Let $G = (V, E, \mathbf{X}, \mathbf{T})$ define a directed, weighted, temporal transaction graph, where $V$ represents Bitcoin transaction vertices, $E$ denotes directed UTXO fund flows, $\mathbf{X} \in \mathbb{R}^{|V| \times d}$ is the feature tensor, and $\mathbf{T}$ supplies confirmed block timestamps. The objective is to formulate a temporal graph attention architecture that: (i) projects continuous inter-transaction time intervals through learnable Fourier parameters optimized directly via gradient descent; (ii) simultaneously identifies three structural laundering archetypes—Circular Transfers, Layering Chains, and Smurfing/Fan-Out patterns—leveraging a shared latent temporal manifold; and (iii) isolates time-ordered, causal subgraphs per alert to support defensible regulatory SAR filings, operating without future data leakage.}


\section{Problem Formulation}
\label{sec:intro_formulation}

\subsection{Motivation}
\label{subsec:motivation}

Three convergent developments motivate this work:

\begin{enumerate}
	\item \textbf{Expanding Scale of Digital Asset Laundering:} Compliance penalties for financial surveillance failures reached unprecedented levels globally~\cite{chainalysis2023}. Concurrently, rapid settlement speeds and decentralized exchange protocols allow illicit operators to move millions across hundreds of addresses in seconds, necessitating scalable graph-native tools.

	\item \textbf{Advances in Temporal Graph Learning:} Modern architectures such as TGAT~\cite{xu2020tgat} and TGN~\cite{rossi2020tgn} have established continuous-time graph attention. Adapting these mechanics to multi-typology classification and compliance-grade explainability, however, remains unexplored in cryptocurrency forensics.

	\item \textbf{Regulatory Demand for Model Transparency:} Enforcement agencies (FATF, FinCEN) increasingly mandate that automated risk scoring provide clear, auditable evidentiary justifications. Optimization-based explainers like GNNExplainer~\cite{ying2019gnnexplainer} offer a rigorous path toward automated, human-readable forensic subgraphs.
\end{enumerate}

\subsection{Research Aim}
\label{subsec:aim}

\begin{quote}
\textit{To design, implement, and validate a Temporal Graph Attention Network equipped with learnable Fourier time encoding for explainable multi-pattern Anti-Money Laundering detection in cryptocurrency transaction networks.}
\end{quote}

\subsection{Objectives}
\label{subsec:objectives}

The investigation advances across four concrete technical objectives:

\begin{enumerate}
	\item[\textbf{O1}] \textbf{Temporal Graph Pipeline:} Construct a directed, weighted temporal graph from the Elliptic Bitcoin benchmark, mapping transaction records to vertices and timestamped UTXO disbursements to directed edges across 49 sequential time windows, while enforcing a strictly chronological, leak-free partition.

	\item[\textbf{O2}] \textbf{Trainable Fourier Time Encoding:} Formulate and implement learnable Fourier parameters—frequencies ($\boldsymbol{\omega}$) and phase shifts ($\boldsymbol{\phi}$)—within the temporal attention mechanism, permitting end-to-end backpropagation to capture the non-stationary velocity of laundering transfers.

	\item[\textbf{O3}] \textbf{Multi-Typology Joint Architecture:} Construct pattern-specific detection heads atop a shared temporal latent representation to classify three structural typologies: (a) Circular Transfers, (b) Layering Chains, and (c) Smurfing/Fan-Out structures, supervised by a class-weighted composite loss.

	\item[\textbf{O4}] \textbf{Forensic Subgraph Explainability:} Adapt GNNExplainer to generate compact, chronologically ordered subgraph evidence for individual predictions, linking flagged transactions directly to automated SAR narratives.
\end{enumerate}

\noindent \textbf{Objective 5 (Future Scope):} Comprehensive benchmarking against GCN, GraphSAGE, GNN-LSTM, and static GAT baselines with extensive metric ablations and temporal stress-testing is scheduled for Dissertation Phase~2.

\subsection{Scope of the Study}
\label{subsec:scope}

\textbf{Phase 1 Scope (this document):}
\begin{itemize}
	\item Mathematical formulation and software implementation of the temporal graph assembly pipeline (O1).
	\item Design, mathematical derivation, and implementation of the Learnable Fourier Time Encoder inside TGAT attention, verifying non-zero gradient flow (O2).
	\item Implementation of the multi-pattern TGAT backbone and parallel classification heads (O3).
	\item Integration of GNNExplainer for per-pattern evidence subgraph generation and interactive visualization (O4).
	\item Target Benchmark: The Elliptic Bitcoin Dataset (203,769 vertices, 234,355 edges, 49 block intervals, 166 initial features expanded to 172 dimensions).
\end{itemize}

\textbf{Deferred to Phase 2:}
\begin{itemize}
	\item Exhaustive hyperparameter tuning and model training to final asymptotic convergence.
	\item Systematic empirical benchmarking against baseline models (GCN, GraphSAGE, GNN-LSTM, static GAT).
	\item Full-spectrum statistical evaluation across F1-score, AUC-ROC, Precision, Recall, and AUPRC.
	\item Complete ablation experiments isolating frequency learnability and individual feature contributions.
	\item Cross-temporal robustness and domain drift evaluations across distant block intervals.
	\item Formal quantitative auditing of explanation fidelity and subgraph compactness.
\end{itemize}

\subsection{Expected Contributions}
\label{subsec:contributions}

This research provides four principal contributions:
\begin{enumerate}
	\item \textbf{A Trainable Fourier Time Encoding Mechanism:} An attention-integrated formulation that optimizes harmonic frequencies via gradient descent, tailoring temporal sensitivity to the heavy-tailed velocity profiles of illicit crypto transfers.
	\item \textbf{A Unified Multi-Typology TGAT Architecture:} A single 128-dimensional latent representation supporting concurrent detection of three structural laundering patterns, reducing computational footprint while eliminating isolated per-model pipelines.
	\item \textbf{An Automated Subgraph Evidence Generator:} A GNNExplainer-driven extraction pipeline that derives compact, chronologically indexed transaction chains for compliance review and automated SAR generation.
	\item \textbf{A Rigorous Leak-Free Temporal Protocol:} A strictly chronological preprocessing and evaluation pipeline enforcing causal neighbor masking and training-only feature scaling, establishing a reliable baseline for temporal financial graph research.
\end{enumerate}
