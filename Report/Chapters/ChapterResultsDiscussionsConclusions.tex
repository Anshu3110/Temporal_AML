\section{Phase 1 Summary and Conclusions}
\label{sec:phase1_conclusions}

Phase~1 concludes with the complete theoretical formulation, software engineering, and preliminary empirical verification of TemporalAML. Accomplishments across the core technical objectives include:

\begin{enumerate}
    \item \textbf{Objective 1: Temporal Graph Construction (Completed):} Developed an automated, leak-free data ingestion pipeline converting raw Elliptic tables into a PyTorch Geometric \texttt{Data} structure spanning 203,769 vertices and 234,355 directed edges. Node attributes were expanded from 166 to 172 dimensions by appending six engineered topological indicators (degree dynamics, fan-in/fan-out ratios, and local temporal deltas). A strictly chronological train/validation/test split was established, isolating normalizer parameter fitting exclusively to $t \leq 34$ and confirming zero look-ahead leakage via unit test verification.

    \item \textbf{Objective 2: Learnable Fourier Time Encoding (Completed):} Formulated the continuous harmonic projection module (Equation~\ref{eq:fourier_encoding}) as a PyTorch \texttt{nn.Module} parameterized by trainable frequencies $\boldsymbol{\omega} \in \mathbb{R}^{64}$ and phase shifts $\boldsymbol{\phi} \in \mathbb{R}^{64}$. Non-zero gradient propagation through temporal parameters (Equation~\ref{eq:fourier_gradient}) was verified during training. The encoding layer was integrated into \texttt{TGATConv} query, key, and value transformations alongside causal neighborhood masking ($t_j \leq t_i$) to prevent future message aggregation.

    \item \textbf{Objective 3: Multi-Pattern TGAT (Implemented, Training In Progress):} Engineered the end-to-end \texttt{MultiPatternTGAT} architecture combining a two-layer shared encoder ($172 \to 128 \to 128$) with three parallel classification heads for Circular Transfers, Layering Chains, and Smurfing dispersals. Ground-truth typology annotations were derived using Tarjan's SCC, temporal directed BFS, and degree thresholds. Preliminary training runs confirmed rapid convergence for smurfing identification, with comprehensive training scheduled for Phase~2.

    \item \textbf{Objective 4: Subgraph Explainability (Implemented):} Built the GNNExplainer extraction pipeline (\texttt{src/explain.py}) to optimize edge masks by maximizing mutual information (Equation~\ref{eq:gnnexplainer}). The module constructs chronologically indexed causal subgraphs for positive alerts, coupling model predictions directly to automated SAR narrative generation within an interactive Streamlit compliance interface.
\end{enumerate}

\vspace{0.5em}
\noindent The architectural and theoretical deliverables achieved in Phase~1 satisfy all technical prerequisites, establishing a verified baseline for asymptotic training and comparative benchmarking in Phase~2.

\section{Future Work: Dissertation Phase 2}
\label{sec:future_work}

Phase~2 will expand the empirical foundation through the following research tasks:

\begin{enumerate}
    \item \textbf{Asymptotic Convergence and Loss Calibration:} Complete model training to full convergence employing cosine annealing learning rate schedules and validation-based early stopping. Integrate Focal Loss ($\gamma = 2.0$) to improve gradient stability against the 2.2\% illicit class imbalance.

    \item \textbf{Baseline Benchmarking:} Perform extensive comparative testing on the inductive test split ($t \in [43, 49]$) against standard baselines:
    \begin{itemize}
        \item Rule-based thresholding heuristic.
        \item Static Graph Convolutional Networks (GCN)~\cite{kipf2017gcn}.
        \item Static Graph Attention Networks (GAT)~\cite{velivckovic2018gat}.
        \item Inductive GraphSAGE~\cite{hamilton2017graphsage}.
        \item Decoupled GNN-LSTM hybrid models~\cite{kim2022gnn}.
        \item Fixed-frequency TGAT~\cite{xu2020tgat}.
    \end{itemize}

    \item \textbf{Comprehensive Metric Reporting:} Tabulate per-pattern and composite macro-F1, Precision, Recall, AUC-ROC, and AUPRC scores across chronological test partitions.

    \item \textbf{Systematic Ablation Experiments:} Quantify the marginal contribution of each core component:
    \begin{itemize}
        \item Static TGAT vs.\ Fixed Sinusoidal vs.\ Learnable Fourier encoding (O2 ablation).
        \item Disjoint single-task heads vs.\ joint multi-task loss (O3 ablation).
        \item Raw 166-dimensional attributes vs.\ expanded 172-dimensional topological features (O1 ablation).
    \end{itemize}

    \item \textbf{Cross-Window Temporal Stability:} Measure detection consistency and generalizability across rolling chronological test partitions to evaluate resilience to long-term network drift.

    \item \textbf{Forensic Explanation Auditing:} Quantitatively measure explanation fidelity ($\Delta$F1 under edge removal), subgraph sparsity, and qualitative SAR narrative alignment with compliance guidelines.

    \item \textbf{Binary Illicit Detection Head:} Introduce a dedicated global binary classification head trained concurrently with typology-specific heads to maximize general illicit detection F1.

    \item \textbf{End-to-End Compliance Pipeline:} Conduct structured validation of automated SAR generation against standard regulatory templates to assess real-world triage utility.
\end{enumerate}

\vspace{1em}
\noindent Phase~1 establishes the complete theoretical framework and functional implementation of TemporalAML. By unifying trainable Fourier time encodings, multi-typology classification, and chronologically ordered subgraph extraction, the architecture directly addresses persistent operational bottlenecks in cryptocurrency anti-money laundering. Phase~2 will supply comprehensive empirical benchmarking and ablation audits to confirm performance advantages over baseline methods.
