\section{Major Findings from Literature}
\label{sec:major_findings}

The systematic literature review conducted in Chapter~2 highlights five structural findings informing TemporalAML's engineering:

\begin{enumerate}
    \item \textbf{Atemporal GCNs distort sequential laundering mechanics:} Although early benchmarks~\cite{weber2019anti} proved that graph operations capture relational topology, collapsing timestamps enables look-ahead leakage and erases velocity signals necessary to detect rapid layering.

    \item \textbf{Snapshot discretization discards intra-window velocity:} Evolving weights over discrete intervals~\cite{pareja2020evolvegcn} tracks broad parameter drift but blinds the network to sub-interval transaction tempo, where rapid laundering hops execute within hours.

    \item \textbf{Fixed harmonic projections fail on heavy-tailed distributions:} TGAT~\cite{xu2020tgat} introduced continuous graph attention using fixed sinusoidal frequencies. While effective for linguistic token positions, fixed geometric bases cannot adjust to the bursty, power-law inter-arrival dynamics of blockchain networks.

    \item \textbf{Binary indicators hinder operational compliance:} Existing models produce solitary illicit risk scores, omitting structural typologies and auditable subgraphs required for statutory SAR escalations.

    \item \textbf{Forensic explainability must be chronology-aware:} Although mutual-information edge masking~\cite{ying2019gnnexplainer} extracts localized subgraphs, prior compliance adaptations lack time ordering, preventing direct translation into sequential investigative reports.
\end{enumerate}

\section{Phase 1 Implementation Results}
\label{sec:phase1_results}

\subsection{Dataset Preparation and Graph Construction (O1)}

The following confirmed outcomes are reported for Objective~1:
\begin{itemize}
    \item The three Elliptic CSV files were successfully loaded and joined. All 203,769 transaction node IDs were remapped to contiguous indices $[0, 203768]$ via a bidirectional hash map.
    \item A directed edge index tensor $\mathbf{E} \in \mathbb{Z}^{2 \times 234355}$ was constructed.
    \item Six topological features were engineered and appended, yielding a final feature matrix $\mathbf{X} \in \mathbb{R}^{203769 \times 172}$.
    \item A \texttt{StandardScaler} was fitted exclusively on training-split nodes ($t \leq 34$), with transformation applied to all partitions.
    \item Chronological split masks were assigned: Train ($t \leq 34$: 143,551 nodes), Validation ($35 \leq t \leq 42$: 34,144 nodes), Test ($43 \leq t \leq 49$: 26,074 nodes).
    \item Automated unit tests in \texttt{tests/test\_no\_leakage.py} confirm zero temporal data leakage.
    \item The complete graph is assembled as a PyTorch Geometric (\texttt{PyG}) \texttt{Data} object and persisted to \texttt{data/processed/elliptic\_graph.pt}.
\end{itemize}

\subsection{Learnable Fourier Time Encoding (O2)}

The \texttt{LearnableFourierTimeEncoder} class was implemented in \texttt{src/models.py} with the following confirmed properties:
\begin{itemize}
    \item Learnable frequency parameters $\boldsymbol{\omega} \in \mathbb{R}^{64}$ initialised from $\mathcal{N}(0, 0.01)$, declared as \texttt{nn.Parameter} for gradient tracking.
    \item Learnable phase parameters $\boldsymbol{\phi} \in \mathbb{R}^{64}$ initialised to zero.
    \item Encoding output $\Phi(\Delta t) \in \mathbb{R}^{128}$ for any input time delta $\Delta t \geq 0$.
    \item Verified gradient flow: $\frac{\partial \mathcal{L}}{\partial \boldsymbol{\omega}} \neq 0$ for all non-zero $\Delta t$ in gradient checks.
    \item Integrated into \texttt{TGATConv} as the temporal component of query, key, and value projections.
    \item \texttt{TemporalNeighborSampler} implements causal masking: only neighbours with $t_j \leq t_i$ are sampled, with up to $K = 20$ neighbours ordered by recency.
\end{itemize}

\subsection{Multi-Pattern TGAT Architecture (O3 — Preliminary)}

The \texttt{MultiPatternTGAT} model has been implemented with the following architecture:
\begin{itemize}
    \item Two-layer TGATConv encoder: $172 \to 128 \to 128$ with 4 attention heads and dropout.
    \item Three parallel classification heads (Circular, Layering, Smurfing), each consisting of a two-layer FFN with ReLU activation and sigmoid output.
    \item Joint multi-task weighted binary cross-entropy loss (Equation~\ref{eq:joint_loss}).
    \item Pattern ground-truth labels mined using Tarjan's SCC (Circular), temporal directed BFS with $\text{length} \geq 3$ and $t_{k+1} \geq t_k$ (Layering), and degree thresholding $d_{\text{out}} \geq 10 \lor d_{\text{in}} \geq 10$ (Smurfing).
\end{itemize}

\noindent \textbf{Preliminary Training Observations:}
\begin{itemize}
    \item The Layering head achieves a validation AUC-ROC of approximately 0.58 in early training epochs, with precision improving as positive-class weighting is tuned.
    \item The Smurfing head achieves a validation AUC-ROC of approximately 0.96 in early training epochs, reflecting the strong discriminative signal provided by the degree-based features (out-degree, fan-out ratio).
    \item The Circular Transfer head produces near-zero recall, consistent with the Bitcoin DAG domain constraint documented in Section~\ref{subsubsec:pattern_heads}.
\end{itemize}

\subsection{GNNExplainer Integration (O4 — Implemented)}

The \texttt{src/explain.py} module implements the GNNExplainer pipeline with the following confirmed components:
\begin{itemize}
    \item Per-node, per-pattern explanation generation: for each flagged node $v^*$ with $\hat{y}^{p}_{v^*} > 0.5$, the pattern-specific head's prediction is explained.
    \item Edge mask optimisation using 200 gradient ascent steps (Adam optimiser, learning rate 0.01).
    \item Top-$k$ edge selection ($k = 10$ by default) from the optimised mask $\mathbf{M}^*$.
    \item Time-ordered evidence subgraph construction: selected nodes sorted by timestamp $t$.
    \item Automated SAR narrative template generation (JSON format).
    \item Integration with the Streamlit forensic dashboard (\texttt{app/dashboard.py}): interactive subgraph visualisation with edge time delta labels and mask confidence scores.
\end{itemize}


\section{Discussion}
\label{sec:discussion}

\subsection{Role of Continuous Time in Relational Attention}

Empirical checks confirm that injecting continuous temporal intervals directly into graph attention modifies representational dynamics. Mapping elapsed intervals $\Delta t$ into a 128-dimensional embedding space enables attention coefficient $\alpha_{ij}$ (Equation~\ref{eq:attention}) to weigh topological similarity against temporal separation. Unlike static attention networks that treat edges from distant epochs as contemporaneous, TemporalAML discounts ancient connections when tracing rapid fund velocity, while capturing long-term associations during dormancy intervals.

The divergence between early Smurfing discriminability ($\text{AUC-ROC} \approx 0.96$) and initial Layering performance ($\text{AUC-ROC} \approx 0.58$) illustrates feature utility. Out-degree and fan-out ratios engineered in Objective~1 supply immediate topological signals for fan-out laundering. Conversely, isolating multi-hop layering requires calibrating Fourier frequency parameters $\boldsymbol{\omega}$ across extended training cycles to capture subtle velocity shifts.

\subsection{Adaptability of the Learnable Fourier Spectrum}

The gradient expression in Equation~\ref{eq:fourier_gradient} confirms that frequency parameters $\boldsymbol{\omega}$ receive non-zero updates for all non-zero time intervals. This mathematical characteristic allows gradient descent to tune projection sensitivity directly to the empirical transaction intervals of the training split. Gradient tracking verifies steady parameter movement ($\|\frac{\partial \mathcal{L}}{\partial \boldsymbol{\omega}}\| > 0$) across batches, demonstrating that the harmonic basis adapts to observed cryptocurrency velocity profiles.

\subsection{Multi-Typology Parameter Efficiency}

Deploying a shared 128-dimensional TGAT backbone across three dedicated heads offers three operational advantages:
\begin{itemize}
    \item \textbf{Parameter Economy:} Consolidating feature extraction into a single two-layer TGAT encoder trims parameter volume by approximately 67\% relative to three detached models.
    \item \textbf{Typological Co-occurrence:} Laundering schemes frequently combine structural behaviors—such as initial smurfing dispersals followed by rapid sequential hops. A shared latent manifold enables the model to encode these intersecting topological signals.
    \item \textbf{Gradient Regularization:} Joint supervision under positive-class-weighted binary cross-entropy stabilizes parameter updates against the extreme 2.2\% illicit class skew.
\end{itemize}

\subsection{Subgraph Evidence for Regulatory Triage}

Internal attention coefficients indicate edge relevance, yet fail to supply legally defensible evidentiary trails because raw attention weights do not guarantee post-hoc decision fidelity~\cite{jain2019attention}. GNNExplainer's mutual information objective (Equation~\ref{eq:gnnexplainer}) optimizes localized subgraphs that reproduce the model's classification state, delivering verifiable, time-ordered evidence chains required for regulatory SAR filings.

\subsection{Current Phase 1 Limitations}

\begin{itemize}
    \item \textbf{Transaction-Level Acyclic Topology:} The Bitcoin UTXO protocol forms a strict DAG across transaction outputs, precluding closed transaction-level cycles in the raw Elliptic graph. The circular detection head is maintained for architectural transferability to wallet-entity topologies.
    \item \textbf{Ongoing Parameter Optimization:} The unified multi-task architecture has completed baseline verification, but full asymptotic convergence, scheduled learning rate decay, and focal loss integration are scheduled for Phase~2.
    \item \textbf{Preliminary Nature of Metrics:} Validation metrics reported in this chapter reflect early training checkpoints and establish feasibility rather than final model capacity.
    \item \textbf{Explainability Quality Audits Deferred:} Statistical audits of subgraph fidelity, edge sparsity, and compliance usability will be executed during Phase~2.
\end{itemize}
