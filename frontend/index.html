    Learnable Fourier Time Encoding

    Novel learnable frequency module where ω parameters are trained end-to-end to discover Bitcoin-specific laundering timescales automatically.

    🏗️ FourierTimeEncoding Architecture

    Input
    t ∈ ℝ(N,)
    Scalar timestamps
    →
    Compute
    ωt + φ
    Learnable ω, φ
    →
    Decompose
    cos(ωt+φ)
    sin(ωt+φ)
    →
    Concat
    [cos ∥ sin]
    Cat on dim=-1
    →
    Output
    ℝ(N, 128)
    2 × d_model
    ParameterShapeInitLearnable
    omega (ω)(64,)N(0, 0.01)✅ Yes
    phi (φ)(64,)zeros✅ Yes
    Total128 params——

    Core Equation

    φ(t) = [cos(ω₁t+φ₁), sin(ω₁t+φ₁), …, cos(ωdt+φd), sin(ωdt+φd)]
    where d=64, output ∈ ℝ128
    Gradient Formula (proven in Cell 21):
    ∂L/∂ω = ∂L/∂cos · (−t·sin(ωt+φ)) + ∂L/∂sin · (t·cos(ωt+φ))

    💡 Why Learnable Encoding Outperforms Fixed

    🔄

    Adaptive Timescales

    Bitcoin AML patterns operate at irregular timescales. Fixed encodings use harmonics of 10000 which don't align with the ~2-week interval structure of the Elliptic dataset.

    🎯

    Task-Specific Frequencies

    Learnable ω parameters converge to frequencies that capture the specific temporal rhythms of illicit transactions — e.g., the clustering seen in time steps 10–12 and 25–27.

    📐

    Phase Alignment (φ)

    The additional learnable phase shift φ allows the encoding to align the sinusoidal cycles to the irregular boundaries between Bitcoin money laundering stages.

    🧮

    End-to-End Optimisation

    Training ω jointly with GCN weights via backpropagation allows temporal features to be co-optimised for the final AML classification objective.
