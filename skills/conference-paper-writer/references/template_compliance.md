# Template compliance
Inspect, never assume from filenames. Preserve originals; edit a copy.
LaTeX: documentclass+options (e.g. conference), packages, macros, bibliography style (.bst), layout, sample content, author-block macros. Compile the unmodified template first to confirm the toolchain and baseline look. Zips in paper/ are extracted to a scratch dir.
PDF: extracted text plus rendered pages (pdftoppm) for layout, tables, figures. DOCX: styles, sections, tables, instructions/comments.
Several templates: compare and pick; ask if unclear. The conference's own template overrides generic IEEE.
Check: paper size, margins, columns, fonts/sizes, spacing, title/author/abstract/keyword formats, heading hierarchy and numbering, equation numbering, figure/table placement and captions (table titles above, figure captions below in standard IEEE), citation and reference style, headers/footers, page numbers, copyright notice, required declarations. Define acronyms on first use; SI units; consistent notation.
Cleanup: remove sample text, instructions, placeholders, unused packages that change layout. Remove the IEEE copyright-block placeholder only if the template says so.
Never call formatting done before rendering and viewing the pages.
