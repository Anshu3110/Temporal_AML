# Submission checklist (Microsoft CMT, verify against current site)
Collect from author (never invent): title, abstract, keywords, authors, order, affiliations, emails, ORCIDs, corresponding author, track/subject area, declarations, copyright/consent forms, registration and presentation requirements, supplementary files.
Check: file format and size, anonymized vs camera-ready version, PDF metadata (author/title/producer), acknowledgments/funding/URLs/self-citations, supplementary anonymity, final-paper upload steps, camera-ready requirements (e.g. PDF eXpress-style checks if the site requires them).
Agent prepares material and guides; author performs submission, registration, payment, signing, acceptance of terms.
