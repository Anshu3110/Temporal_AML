# Conference compliance
Verify live from the official site every run; follow links from the homepage (CFP, tracks, submission, dates, review policy, IEEE Xplore, registration, presentation, CMT, FAQ, copyright/consent, camera-ready, brochures). Log URL, title, date checked, requirement, explicit/inferred, verified Y/N. Log inaccessible pages; never bypass access controls.
- Dates: record verified dates with check date; distinguish confirmed vs outdated. Past deadline: check extension, portal status, alternate opportunities; report, never assume acceptance of late papers.
- Tracks: read current descriptions; map project by problem, method, domain, contribution; document track, subtopic, rationale, uncertainty. Misfit: flag.
- IEEE claims: keep distinct - IEEE-associated conference / accepted / presented / submitted for possible Xplore inclusion / actually in Xplore. Following an IEEE-style template is not IEEE approval. Never invent sponsorship, indexing or guarantees.
- Double-blind: check which stage applies; anonymization differs between submission and camera-ready.
- CMT: see submission_checklist.md. Prepare, never perform, external submission.
- Website vs local template disagreement: document; ask if it affects page limit, anonymity, eligibility, or publication.
