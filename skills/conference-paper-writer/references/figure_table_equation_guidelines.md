# Figures, tables, equations
Inspect existing plots/diagrams first. Every figure/table maps to real project data or architecture; keep a traceable link (script + data file) for each plot. Never fabricate or illustrate synthetic results as real. Readable at final column width (vector PDF preferred, >=300 dpi raster), meaningful labels, units, consistent terms, template caption style, referenced and explained in text, cited if adapted, no redundant or decorative graphics. Equations: numbered per template, symbols defined, notation consistent, mathematically checked, dimensions/units consistent.
